# EUR to SAR

A simple Euro ↔ Saudi Riyal converter, styled to match the UKR2SAR converter.

The default indicative exchange rate is 1 EUR = 4.2419 SAR, based on the EUR/SAR quote displayed for Thursday, October 1, 2026. Rates fluctuate and provider/bank rates may differ. Enter an amount in either field to convert in the other direction. The input also accepts Arabic and Persian numerals and decimal punctuation.

Open `index.html` in a browser to use the converter.

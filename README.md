# EUR to SAR

A simple Euro ↔ Saudi Riyal converter, styled to match the UKR2SAR converter.

The initial exchange rate is an editable-in-code indicative value of 1 EUR = 4.15 SAR. Enter an amount in either field to convert in the other direction. The input also accepts Arabic and Persian numerals and decimal punctuation.

Open `index.html` in a browser to use the converter.
